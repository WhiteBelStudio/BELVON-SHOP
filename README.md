# BELVON SHOP

Cross-platform shop application foundation built with Flutter.

Targets: Windows/PC, Android, iOS and macOS.

The current foundation contains the app shell, catalog UI, favorites state, product cards and a clean architecture ready for a backend/API connection.

This repository is a neutral e-commerce foundation for permitted goods.

## Release CI

GitHub Actions builds Windows, Android, macOS and an unsigned iOS package on pushes to `main`.
